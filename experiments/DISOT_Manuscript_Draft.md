# 5 Experimental Setup

## 5.1 Dataset and Processing
To evaluate the proposed architecture and semantic plugin, we utilized the Amazon Customer Reviews (CDs and Vinyl) dataset. This dataset was selected due to its rich longitudinal sequence of both purchasing behavior and textual review data. To ensure absolute parity when evaluating the structural bias of historical formulations, the evaluation was locked to an exact overlapping cohort of $506$ customers ($N=506$) present in both the historical legacy evaluation split and our proposed forward-looking test split.

## 5.2 Framework Baselines
We evaluated two distinct survival prediction frameworks:
1. **Historical Framework**: The traditional approach prevalent in existing literature, where both behavioral features (e.g., Recency, Frequency, Monetary) and the churn event are defined retrospectively from a single snapshot date.
2. **Universal Framework (Proposed)**: A forward-looking, episode-based survival formulation where churn is defined strictly relative to individual review episodes, effectively decoupling the target definition from historical behavioral proxies.

## 5.3 Semantic Feature Ablation
For both frameworks, we conducted a controlled semantic ablation study using three nested feature configurations:
1. **Behavioral-Only**: Standard RFM proxies without any semantic variables.
2. **Behavioral + VADER**: Integrating standard lexicon-based sentiment scores.
3. **Behavioral + LLM Semantic Trajectories**: Integrating advanced, context-aware semantic features generated by a Large Language Model (e.g., `net_sentiment`, `semantic_variance`, `aspect_entropy`).

## 5.4 Evaluation Metrics
Prediction performance was measured using the Concordance Index (C-index) via a penalized Cox Proportional Hazards model. To rigorously quantify the complementary value of semantic features, we utilized $1,000$ paired bootstrap iterations to estimate the 95% Confidence Interval (CI) for the effect size ($\Delta$ C-index). Additionally, Likelihood Ratio Tests (LRT) were employed to assess nested model significance, and multivariable Hazard Ratios (HR) were extracted for interpretability. Finally, business value was evaluated by simulating a Decision Support System (DSS) retention campaign, comparing Expected Net Benefit (ENB), Return on Investment (ROI), and Resource Allocation Efficiency.

# 6 Results

## 6.1 Architecture Validation
To evaluate the impact of the proposed forward-looking reformulation independently of semantic features, we strictly compared the Behavioral-Only performance of the Historical Framework against the Universal Framework. 

The comparison revealed a fundamental shift in predictive behavior. The Historical Framework achieved a highly inflated apparent C-index of $0.837$. However, this performance was largely driven by historically dominant behavioral proxies (primarily Recency) that were tightly coupled with the original churn formulation, confirming the presence of structural target leakage.

After reformulating the prediction task into the forward-looking Universal setting, the behavioral baseline decreased to a C-index of $0.512$. Although the absolute discrimination decreased, the resulting model represents a substantially more realistic and deployable scenario where future churn can no longer be inferred trivially from historical inactivity patterns. These findings strongly support **H1**, demonstrating that the proposed architecture successfully removes dependence on historically dominant signals, establishing a rigorous prediction space.

## 6.2 Semantic Contribution
The semantic ablation study was subsequently conducted to determine if the Universal architecture could unlock the predictive value of text data. Table 1 summarizes the paired bootstrap evaluation across both frameworks.

**Table 1: Predictive Performance ($\Delta$ C-index) across Frameworks**

| Framework | Feature Configuration | C-index (95% CI) | $\Delta$ C-index (95% CI) |
| :--- | :--- | :--- | :--- |
| Historical | Behavioral Only | $0.810 \ [0.788, 0.832]$ | - |
| Historical | + VADER | $0.826 \ [0.806, 0.847]$ | - |
| Historical | + LLM Semantics | $0.807 \ [0.785, 0.828]$ | $-0.003 \ [-0.009, 0.004]$ |
| Universal | Behavioral Only | $0.557 \ [0.503, 0.615]$ | - |
| Universal | + VADER | $0.596 \ [0.539, 0.648]$ | - |
| Universal | + LLM Semantics | $0.716 \ [0.659, 0.774]$ | $+0.159 \ [0.083, 0.241]$ |

Under the Historical Framework, integrating LLM-derived semantic trajectories yielded no predictive gain ($\Delta$ C-index = $-0.003$). This observation proves that when a prediction problem is formulated such that behavioral proxies dominate, the model reaches *Information Saturation*; the addition of complex semantic features provides negligible complementary value.

Conversely, under the Universal Framework, the addition of LLM semantic features drastically improved prediction performance, yielding a statistically significant $\Delta$ C-index of $+0.159 \ [0.083, 0.241]$. A Likelihood Ratio Test confirmed the structural significance of the LLM features ($\chi^2 = 64.85$, $p < 0.001$). These results powerfully support **H2**: when the structural dominance of behavioral proxies is resolved, semantic trajectories act as an independent and highly valuable source of predictive information.

### Interpretability Analysis
Multivariable Cox regression highlighted several semantic variables that remained statistically significant predictors of churn after adjusting for behavioral baselines. Specifically, `semantic_variance` ($HR = 1.402, p < 0.001$) and `positive_minus_negative_ratio` ($HR = 1.419, p = 0.001$) emerged as strong risk indicators, suggesting that high volatility in user satisfaction often immediately precedes dormancy.

## 6.3 Decision Support Evaluation
To investigate whether improved prediction quality translates into tangible business value (**H3**), we simulated a targeted intervention campaign utilizing the predictions from both frameworks under an identical budget constraint (Cost: \$2,000).

**Table 2: DSS Business Value Simulation**

| Metric | Historical Framework DSS | Universal Framework DSS |
| :--- | :--- | :--- |
| Targeting Precision | $1.00$ | $0.42$ |
| Expected Net Benefit | $\$4,000$ | $\$550$ |
| ROI | $200\%$ | $27.5\%$ |
| Resource Allocation Efficiency | $3.00$ | $1.27$ |

The Historical Framework achieved a biologically implausible targeting precision of $1.00$ (100%), driven entirely by the structural leakage of Recency into the target definition. Such a policy cannot be deployed in practice, as it essentially intervenes on customers *after* they have already exhibited the defining behavior of churn. 

In stark contrast, the Universal Framework produced realistic, economically feasible intervention recommendations. It achieved a practical Targeting Precision of $42.5\%$ and generated a positive Expected Net Benefit of $\$550$ (ROI: $27.5\%$). This confirms that the semantic-enhanced, forward-looking predictions can be effectively translated into proactive business value, successfully validating **H3**.

## 6.4 Discussion
Our experimental results highlight a critical methodological flaw in applying advanced NLP techniques to historical survival analysis formulations. Prior research frequently attributes the failure of textual features to improve churn models to either poor feature extraction or the inherent noise of text data. However, our findings suggest a different conclusion: the failure is often structural.

When a churn problem defines the target event using the very behavioral proxies (e.g., elapsed time since last purchase) that serve as input features, the resulting model suffers from *Behavioral Dominance*. The prediction space becomes saturated, leaving no mathematical room for semantic variables to contribute. By reformulating the problem around a forward-looking, episode-based schema, we effectively decoupled the target from the historical proxies. Only in this unconstrained space did the true value of the LLM's semantic trajectories emerge, proving that textual data contains rich, complementary signals regarding customer satisfaction and impending churn risk that pure behavior cannot capture.

# 7 Conclusion

In this paper, we proposed a Universal Survival Framework that integrates Large Language Model (LLM) semantic trajectories into churn prediction modeling. We demonstrated that historical formulations inherently suppress the value of textual features due to structural behavioral dominance. By reformulating the prediction problem into a forward-looking, episode-centric architecture, we successfully isolated the true predictive value of semantic data. Our empirical evaluation confirmed that integrating LLM-derived sentiment dynamics provides a highly significant performance boost ($\Delta$ C-index of $+0.159$) over behavioral-only baselines. Furthermore, simulating a Decision Support System proved that these refined predictions yield realistic and deployable business interventions, achieving a substantial Return on Investment. Future research will explore real-time streaming architectures for semantic feature generation and assess the generalizability of the Universal Framework across multi-domain e-commerce datasets.
